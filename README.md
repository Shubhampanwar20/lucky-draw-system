# 🎉 Lucky Draw System

A simple Lucky Draw System built using React where users can register, add scores, and randomly select a winner.

## 🚀 Features
- User Registration
- Add Score
- Random Winner Selection
- Clean UI with animations

## 🛠️ Tech Stack
- React.js
- JavaScript
- CSS
